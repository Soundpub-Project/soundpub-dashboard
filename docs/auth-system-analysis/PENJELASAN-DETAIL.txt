   Error:        "Unable to exchange external code"
   
   Root Cause:   Server Supabase Anda tidak punya konfigurasi Google OAuth.

                 • GOTRUE_EXTERNAL_GOOGLE_ENABLED

                 • GOTRUE_EXTERNAL_GOOGLE_SECRET
                 • GOTRUE_EXTERNAL_GOOGLE_REDIRECT_URI
   
   Dampak:       User tidak bisa login pakai Google account
   
   Solusi:       Tambahkan env vars ke .env file (dijelaskan di dokumentasi)


2. ❌ MASALAH AUTO ROLE ASSIGNMENT
   ────────────────────────────────────────────────────────────────────────────
   Problem:      User baru yang daftar manual → dapat role 'user'
                 Seharusnya → dapat role 'artist'
   
   Root Cause:   Trigger function soundpub.handle_new_user() tidak lengkap:
                 • Hanya assign role 'user' ❌
                 • Tidak set parent_label_id ❌
                 • Tidak create entry di soundpub.artists ❌
   
   Comparison:   SSO (ICCN) login → sudah benar (role artist + label ICCN)
                 Manual signup → salah (role user + no label)
   
   Dampak:       Artist baru tidak bisa akses fitur artist
                 Artist tidak keliatan di dashboard label
                 Inconsistency antar auth methods
   
   Solusi:       Update trigger function via SQL migration

AFTER (Code Baru):
───────────────────────────────────────────────────────────────────────────────
CREATE OR REPLACE FUNCTION soundpub.handle_new_user()
RETURNS TRIGGER AS $$
DECLARE
  soundpub_label_id UUID;
  new_artist_id UUID;
BEGIN
  -- 0. Cari Soundpub Music label ID
  SELECT id INTO soundpub_label_id
  FROM soundpub.profiles
  WHERE email = 'label@soundpub.id'
  LIMIT 1;

  -- 1. Create profile WITH parent_label_id ✅
  INSERT INTO soundpub.profiles (
    id, email, full_name, 
    parent_label_id,  -- ✅ DITAMBAHKAN!
    status, password_set, artist_profile_completed
  ) VALUES (
    NEW.id, NEW.email, COALESCE(...),
    soundpub_label_id,  -- ✅ Assign ke Soundpub Music
    'active', true, false
  );
  
  -- 2. Assign role 'artist' ✅ DIUBAH!
  INSERT INTO soundpub.user_roles (user_id, role)
  VALUES (NEW.id, 'artist'::soundpub.app_role);  -- ✅ 'artist' bukan 'user'
  
  -- 3. Create artist entry ✅ DITAMBAHKAN!
  INSERT INTO soundpub.artists (
    id, user_id, label_id, artist_name, status
  ) VALUES (
    gen_random_uuid(), NEW.id, soundpub_label_id, 
    COALESCE(...), 'active'
  );
  
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;
───────────────────────────────────────────────────────────────────────────────

Yang Berubah:
  ✅ Role: 'user' → 'artist'
  ✅ parent_label_id: NULL → Soundpub Music ID
  ✅ Artist entry: Tidak ada → Dibuat otomatis

## Classification and state rules

`PHASE4_AUTH` retains provider/session/recovery integration. `LATER_PHASE` retains active application dependencies pending domain replacement, including production-active legacy adapter branches. `LEGACY_ONLY` means no static import path from `src/main.tsx` for retained modules, or unused Supabase import in `Royalties.tsx`; it is not permission to delete. `TEST_ONLY` applies to test/safety evidence, not reachable diagnostics. `MIGRATED` requires proven replacement; no such claim made here.

`FRONTEND_ADAPTER_READY` means routing/transport exists for a bounded operation; it does not certify DTO, Auth, runtime, or business parity. `BLOCKED` records a concrete missing contract/behavior. `DEFERRED` retains Auth, unused modules, or explicitly deferred gallery. Endpoint/service replacements are proposed unless explicitly labeled existing. Auth requirements below describe necessary target capability inferred from caller/resource; they are not a fresh attestation of deployed RLS or grants. All target policies require server-derived actor, current status, ownership/tenant relation and default deny; UI guards alone do not authorize.

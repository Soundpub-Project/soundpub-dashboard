🎓 PROBLEM SUMMARY
───────────────────────────────────────────────────────────────

Masalah:
  File bernama: _env (underscore)
  Harusnya:     .env (dot)

Kenapa Error?
  Docker Compose HANYA membaca file .env
  File _env tidak dibaca otomatis
  → 131+ environment variables jadi blank
  → POSTGRES_PASSWORD blank
  → Database gagal start (unhealthy)
  → Semua service lain gagal (dependency)

Solusi:
  mv _env .env
  docker compose restart

Root Cause:
  - Typo saat buat file
  - File transfer issue
  - Git ignore workaround
  
Prevention:
  - Selalu gunakan nama .env
  - Verify dengan: ls -la .env
  - Use template dari official repo

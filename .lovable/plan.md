## Buat File `.env.example` untuk Integrasi SSO

Saya akan membuat file `.env.example` di root project yang berisi semua environment variable yang dibutuhkan untuk frontend (Vite) — khususnya konfigurasi SSO ICCN.

### Catatan Penting Dulu

Di Lovable, ada **2 tempat** environment variable disimpan:

| Tempat | Untuk | Cara isi |
|---|---|---|
| **Frontend `.env`** (Vite, prefix `VITE_`) | Dipakai di browser/React | Otomatis di-generate Lovable, hanya berisi `VITE_SUPABASE_*`. Variable `VITE_SSO_*` perlu ditambah manual lewat **Workspace Settings → Build Secrets** |
| **Cloud Secrets** (backend) | Dipakai di Edge Function | Sudah dikelola lewat tool `add_secret` (tidak ada di `.env`) |

File `.env.example` yang akan saya buat berfungsi sebagai **dokumentasi/referensi** — bukan file aktif.

### Isi File `.env.example`

```env
# =============================================================
# SoundPub Dashboard - Environment Variables Example
# =============================================================
# File ini hanya REFERENSI. Lovable mengelola .env aktual secara
# otomatis. Untuk menambah VITE_SSO_* di production, tambahkan
# di Workspace Settings -> Build Secrets.
# =============================================================

# ---------- Supabase / Lovable Cloud (auto-generated) ----------
VITE_SUPABASE_PROJECT_ID="opkvvdgnhhopkkeaokzo"
VITE_SUPABASE_URL="https://opkvvdgnhhopkkeaokzo.supabase.co"
VITE_SUPABASE_PUBLISHABLE_KEY="<auto-generated-by-lovable>"

# ---------- SSO ICCN (Frontend / keycloak-js) ----------
# Base URL Keycloak ICCN
VITE_SSO_BASE_URL="https://sso.iccn.or.id"

# Realm Keycloak
#   Staging:    playground
#   Production: PORTALICCN
VITE_SSO_REALM="playground"

# Client ID terdaftar di Keycloak ICCN
VITE_SSO_CLIENT_ID="soundpub"

# ---------- Google Analytics (opsional) ----------
# VITE_GA4_MEASUREMENT_ID="G-XXXXXXXXXX"
```

### Catatan Backend (Cloud Secrets — bukan di `.env`)

Sebagai dokumentasi tambahan di komentar file, akan saya cantumkan daftar Cloud Secrets yang sudah/perlu di-set lewat Lovable Cloud (bukan via `.env`):

| Secret | Nilai contoh |
|---|---|
| `SSO_REALM_URL` | `https://sso.iccn.or.id/realms/playground` |
| `SSO_CLIENT_ID` | `soundpub` |
| `ICCN_MEDIA_LABEL_ID` | UUID label ICCN Media di tabel `profiles` |
| `XENDIT_SECRET_KEY` | dari dashboard Xendit |
| `XENDIT_WEBHOOK_TOKEN` | dari dashboard Xendit |
| `RESEND_API_KEY` | dari dashboard Resend |
| `GCS_*` | konfigurasi Google Cloud Storage |
| `GA4_MEASUREMENT_ID` | ID Google Analytics |

### File yang Akan Dibuat

- **`.env.example`** (root project) — berisi template lengkap dengan komentar penjelasan untuk frontend variables + dokumentasi inline daftar Cloud Secrets backend.

### Tidak Ada Perubahan Lain

Tidak ada code change. Hanya file dokumentasi `.env.example`. File `.env` aktual tetap dikelola otomatis oleh Lovable dan tidak akan diedit.
